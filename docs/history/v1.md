# FlashRL V1 History

FlashRL began as a Playwright-driven Chrome Dino assignment with a convolutional
DQN. The original implementation read three structured JavaScript values and
resized them into an `84x84` tensor, so the committed V1 checkpoints were not
validated pixel-policy artifacts. They also lacked seeds, exact configuration,
environment identity, checkpoint hashes, and episode-level held-out results.

The V1 tree included eight approximately 20 MB PyTorch checkpoints, a Windows
ChromeDriver binary, browser-game vendor files, debug frames, logs, and
TensorBoard events. These generated artifacts were removed from the supported
V2 source tree; they remain recoverable from Git history before commit
`46994cc`.

## Invalid Schema-V1 Benchmark Artifacts

Before V2 work, the local checkout contained untracked:

- `results/dqn_state.csv`;
- `results/dqn_state.jsonl`;
- `reports/benchmark_summary2.md`.

The DQN result contained 500 evaluation episodes from
`runs/dqn_20260609T211424Z/checkpoint.pt` at commit `49bfac1`. The checkpoint
reported 159,657 training frames, but every result row reported
`train_frames=0`. The Markdown summary pooled those rows with five older DQN
smoke episodes while comparing them with only five random and five rule-policy
episodes. Aggregation ignored checkpoint, training seed, environment version,
and hyperparameters.

Those files demonstrated the benchmark-identity bug tracked by GitHub issue #5,
but they cannot support a performance claim and were removed rather than
published. V2 results use versioned manifests and held-out multi-seed evidence.
